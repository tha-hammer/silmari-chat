# Review Research — Voice-of-Customer Scoring Matrix

**Purpose:** Turn raw customer reviews (Amazon, Reddit, Quora, forums, support
tickets, testimonials) into a *scored* matrix of the language customers actually
use, ranked by how much each theme should drive the copy.

**Rule:** Every row comes from a real review/quote. Do not invent themes.

---

## The Scoring Formula

```
Importance = Intensity × Repeatability × Scale
```

The highest-Importance phrases become the backbone of headlines, hooks, pain
lists, and objection answers.

### Scoring bands

| Dimension | Question | 1–3 | 4–7 | 8–10 |
|-----------|----------|-----|-----|------|
| **Intensity** | How powerful is this topic? | MINOR — easy to forget | MEDIUM — noticeable | MAJOR — life-changing |
| **Repeatability** | How often does it occur for the customer? | INFREQUENT — rarely | FREQUENT — weekly | CONSTANT — daily/hourly |
| **Scale** | What % of people does it affect? | low % (e.g. 23% → 2) | mid % (e.g. 55% → 5) | high % (e.g. 81% → 8) |

> **Scale tip:** divide the percentage by 10 to get the 1–10 score
> (81% → 8, 55% → 5, 23% → 2).

---

## The Matrix (fill one row per theme found in reviews)

| Phrase / Term / Keyword | Frequency (count) | % of Frequency | Positive / Negative | Intensity (1-10) | Repeatability (1-10) | Scale (1-10) | **Importance** |
|--------------------------|-------------------|----------------|---------------------|------------------|----------------------|--------------|----------------|
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |

- **Phrase / Term / Keyword** — the exact wording customers use (preserve their voice).
- **Frequency** — how many times this topic appears across the reviews mined.
- **% of Frequency** — that count as a share of all coded themes.
- **Positive / Negative** — is the sentiment praise or complaint?
- **Importance** — Intensity × Repeatability × Scale (compute, then sort descending).

---

## Output of this worksheet

A ranked list of the customer's own phrases, highest Importance first. This feeds:
- **Pain list / Vision list** (CopyPlatform sections 12–13)
- **Objection answers** (grounded in real complaints, not guesses)
- **Headlines & hooks** (use their words, not yours)
